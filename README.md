# Waste Classification App ♻️

A machine learning web application built with **TensorFlow** and **Streamlit** that classifies waste images into two categories: **Organic** and **Recyclable**.  

This project promotes better waste management practices by providing an easy‑to‑use tool for classification.

---

## 🚀 Features
- Upload images (JPG/PNG up to 200MB).
- Real‑time classification with confidence scores.
- Simple and modern UI powered by Streamlit.
- Model trained on custom datasets of organic and recyclable waste.
